# 🇩🇰 FastLearn — Brutalist LingQ AI Danish Tutor

Повністю клієнтський, мінімалістичний та брутальний веб-застосунок для вивчення датської мови у форматі інтерактивного діалогу з ШІ в стилі **LingQ**.

Інтегровано з [**Antigravity Client**](https://github.com/YaroslavSamchuk/AntigravityClient) для прямого доступу до моделей ШІ та підготовлено до **миттєвого деплою на Koyeb / Docker**.

---

## ⚡ Особливості архітектури
- **🚀 Повна готовність до Koyeb & Docker**: Проєкт містить оптимізований multi-stage `Dockerfile` та легкий production-сервер `server.js` (Node.js 22), який автоматично слухає порт `$PORT` (8000) та віддає скомпільований SPA разом із маршрутом перевірки здоров'я (`/health`).
- **⚡ Вбудований реверс-проксі для Antigravity (`/v1internal`)**: Сервер автоматично інжектує системний `User-Agent: antigravity/cli/...` для взаємодії з бекендом Google Antigravity без браузерних CORS-блокувань.
- **🔐 Google OAuth (PKCE) або Gemini API Key**: Локально ви можете авторизуватися через Google в 1 клік без API ключів, а на віддаленому сервері чи GitHub Pages — використовувати швидкий Gemini API Key.
- **100% збереження прогресу у клієнті**: Усі діалоги, персональний словник та налаштування зберігаються у вашому браузері (`localStorage`).
- **Синтез мови Web Speech API**: Природна вимова датських слів та речень (`da-DK`) без сторонніх платних TTS-сервісів.
- **Експорт в Anki**: Експорт персонального словника у `.tsv` / `.csv` для щоденного інтервального повторення.

## ☁️ Деплой на Koyeb (Покрокова інструкція)

Деплой на платформу **Koyeb** займає приблизно 2 хвилини:

### Крок 1: Запуште проєкт у свій GitHub-репозиторій
```bash
git add .
git commit -m "Prepare FastLearn for Koyeb hosting"
git push origin main
```

### Крок 2: Створіть сервіс у панелі Koyeb
1. Перейдіть на [app.koyeb.com](https://app.koyeb.com/) та увійдіть.
2. Натисніть **Create App** або **Create Service** -> оберіть **GitHub**.
3. Оберіть ваш репозиторій з **FastLearn**.
4. У розділі **Builder** оберіть **Dockerfile** (Koyeb автоматично підхопить готовий файл `Dockerfile` у корені).
5. У розділі **Ports / Exposing your service**:
   - **Port**: `8000`
   - **Protocol**: `HTTP`
   - **Route**: `/`
6. *(Опціонально)* У розділі **Health Checks**:
   - **Type**: `HTTP`
   - **Path**: `/health`
   - **Port**: `8000`
7. Натисніть кнопку **Deploy**!

Koyeb автоматично збере Docker-образ, запустить health check і видасть безкоштовний публічний SSL-домен (наприклад, `https://fastlearn-<your-org>.koyeb.app`).

## 💻 Локальний запуск

### Варіант 1: Dev-сервер з гарячим перезавантаженням
```bash
# З кореня проєкту
npm run dev

# Або з папки frontend
cd frontend
npm install
npm run dev
```
Відкрийте `http://localhost:5173`.

### Варіант 2: Локальний запуск продакшн-сервера
```bash
npm run build
npm start
```
Відкрийте `http://localhost:8000`.

### Варіант 3: Запуск через Docker
```bash
docker build -t fastlearn .
docker run -p 8000:8000 fastlearn
```

## 🧩 Функціонал LingQ

1. **Інтерактивні слова-токени**:
   - 🔵 **Нове слово (0)** — синій акцент.
   - 🟡 **На вивченні 1 (1)** — фірмовий жовтий LingQ колір.
   - 🟡 **Знайоме (2)** — м'який жовтий відтінок.
   - ⚪ **Вивчене (3)** — чистий звичайний текст.
2. **Миттєвий поп-ап слова**:
   - 🔊 Озвучка слова датською.
   - 🇺🇦 Переклад на українську (можна редагувати прямо в інтерфейсі).
   - 💡 Датські синоніми з можливістю прослухати кожен.
   - ⚡ Гарячі клавіші для зміни статусу: натискайте `1`, `2`, `3` або `0` на клавіатурі.
3. **Виділення фраз та ідіом**:
   - Виділіть фрагмент тексту мишкою, щоб відкрити плаваючу панель дій:
     - 🔊 Озвучити фразу
     - 🇺🇦 Отримати миттєвий переклад фрази через ШІ
     - 💾 Зберегти фразу як вираз у свій словник
4. **Педагогічний блок аналізу реплік**:
   - Якщо учень припустився граматичної помилки або неправильного порядку слів:
     - 💡 *Що ви мали на увазі*
     - ✨ *Як сказати природніше датською* (з озвучкою 🔊)
     - ℹ️ *Пояснення граматичного правила*
