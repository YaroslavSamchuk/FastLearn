# 🇩🇰 FastLearn — Brutalist LingQ AI Danish Tutor

Повністю статичний, мінімалістичний та брутальний клієнтський веб-застосунок для вивчення датської мови у форматі інтерактивного діалогу з ШІ в стилі **LingQ**. Працює **100% на клієнті** (Serverless / Static SPA), ідеально підходить для **GitHub Pages**.

---

## ⚡ Особливості архітектури
- **100% на клієнті**: Без серверів, без Python, без MongoDB. Усі дані (діалоги, словник, налаштування) зберігаються локально у `localStorage` вашого браузера.
- **Пряме підключення до Google Gemini**: Ви вказуєте власний API ключ у налаштуваннях (зберігається тільки у вашому браузері). За замовчуванням обрано швидку та економну модель `gemini-2.5-flash` (або `gemini-2.0-flash-lite`, `gemini-1.5-flash` чи будь-яку іншу).
- **Готовий до GitHub Pages**: Збірка генерує відносні шляхи (`base: './'`), а також налаштовано автоматичний GitHub Actions workflow (`.github/workflows/deploy.yml`).
- **Синтез мови без бекенду**: Озвучка слів, речень та реплік через рідний браузерний **Web Speech API** для датської мови (`da-DK`).
- **Експорт в Anki**: Експорт вашого персонального словника у `.tsv` / `.csv` в 1 клік для карток повторення.

---

## 🧩 Функціонал LingQ

1. **Інтерактивні слова-токени**:
   - 🔵 **Нове слово (0)** — синій акцент.
   - 🟡 **На вивченні 1 (1)** — фірмовий жовтий LingQ колір.
   - 🟡 **Знайоме (2)** — м'який жовтий відтінок.
   - ⚪ **Вивчене (3)** — чистий звичайний текст.
2. **Миттєвий поп-ап слова**:
   - 🔊 Озвучка слова датською.
   - 🇺🇦 Переклад на українську (можна редагувати прямо в інтерфейсі).
   - 💡 Датські синоніми з можливістю прослухати кожен.
   - ⚡ Гарячі клавіші для зміни статусу: натискайте `1`, `2`, `3` або `0` на клавіатурі.
3. **Виділення фраз та ідіом**:
   - Виділіть фрагмент тексту мишкою, щоб відкрити плаваючу панель дій:
     - 🔊 Озвучити фразу
     - 🇺🇦 Отримати миттєвий переклад фрази через Gemini
     - 💾 Зберегти фразу як вираз у свій словник
4. **Педагогічний блок аналізу реплік**:
   - Якщо учень припустився граматичної помилки або неправильного порядку слів:
     - 💡 *Що ви мали на увазі*
     - ✨ *Як сказати природніше датською* (з озвучкою 🔊)
     - ℹ️ *Пояснення граматичного правила*

## 🚀 Швидкий запуск

### Варіант 1: Локальний запуск для розробки
```bash
cd frontend
npm install
npm run dev
```
Відкрийте `http://localhost:5173`.

### Варіант 2: Збірка для GitHub Pages
```bash
cd frontend
npm run build
```
Готові статичні файли створюються у папці `frontend/dist/`. Завантажте їх на GitHub Pages або дозвольте GitHub Actions автоматично опублікувати сайт при коміті в `main`.

## 🔑 Налаштування Gemini API Key
1. Отримайте безкоштовний ключ на [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Натисніть іконку **⚙ Налаштування** у правому верхньому куті FastLearn.
3. Вставте ключ та натисніть кнопку **«Перевірити»** — застосунок підтвердить готовність ключа.
4. Натисніть **«Зберегти налаштування»**.
